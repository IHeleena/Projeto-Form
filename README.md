O projeto consiste em um formulário que permite preencher informações relacionadas a veículos por meio de campos de texto e opções de seleção, organizados em uma interface temática.
Praticar a construção de formulários HTML, a organização de elementos na página e a personalização de estilos com CSS, explorando a criação de interfaces e a interação com o usuário.
Tecnologias:
HTML5
CSS3
Aprendizados
Estruturação de formulários.
Utilização de campos de entrada e elementos de seleção.
Organização e semântica do HTML.
Estilização e personalização visual com CSS.
